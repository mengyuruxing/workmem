# test

`node --test`，不引测试框架。

## 优先级

1. `entry`：解析/序列化往返、未知字段保留、CRLF、重复 id、损坏条目、`##` 正文警告。
2. `store`：原子写、mtime 冲突、写失败不留半截文件。
3. `search`：自然问句、短问句、闲聊空手、项目系数、冷热、权重、手动无门槛。
4. `policy`：告诉/跑腿/闲聊、明说“记一下”、跑腿轮只放行坑。
5. `health`：绿/黄/红迁移、空库、连续 10 轮、30 轮 <10%、写入失败。
6. `snapshot`：快照 → 修改 → 回滚 → 内容一致；回滚前安全快照。
7. `weights`：默认矩阵、非法档位补齐、改一格生效。
8. `mode`：自动分类、平滑、手动锁、AI 覆盖优先级。

## 样例

统一使用 `test/fixtures/sample/`，不要写真实记忆目录。正式数据目录启动时必须为空，测试夹具不会被插件加载。
