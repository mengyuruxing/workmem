## 风险与对策

| 风险 | 对策 |
|---|---|
| Markdown 手改破坏格式 | 容错解析、保留未知字段、损坏条目不参与检索、面板可见 |
| 面板和 AI 同时写 | 单进程串行队列 + mtime 冲突检测 + 原子替换 |
| 跑腿轮硬拦误伤 | 明说“记一下”和面板手写放行；拒绝原因写清楚；试用 50 轮后评估 |
| 自动模式判断抖动 | 置信度 + 连续两轮同向才切；手动随时锁 |
| 权重调乱导致该出现的没出现 | 默认值可用；恢复默认；自检显示因子；权重只影响已过门槛条目 |
| 5 个文件变大 | 5 MB 阈值提示；第一版不拆；后续再加分片 |
| 快照占空间 | 文本很小；不自动删；面板显示大小，手动清理 |
| 隐私 | 本地、不联网、不存密钥；快照同级别保护 |
| 时间/编码差异 | ISO 8601 带时区；UTF-8 无 BOM；读写容忍 CRLF |
